Tests give useful permanent coverage for local invariants (locking, receipt deltas, expiry boundaries, gateway schema/status behavior, executor journal refusal, and guard classification). Their confidence does not extend beyond fixtures: many inject fake `AuthorityStore`, fake session/HTTP clients, verifier lambdas, patched SSH/key and service functions, or temporary SQLite/config. Such tests are valid unit/integration tests for the local boundary, but cannot prove real TLS, real phone pairing, real signatures/passkeys, remote node fencing, Dell readiness, or automatic failover. In particular, a signed-looking fixture or a callback that returns true is not evidence that production keys are provisioned and verified.
