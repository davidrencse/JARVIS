# Audit, November 2026: what changed and why

Overhaul of 2026-11-07. Every edited file has a `.pre-overhaul` backup next to it. Nothing
was restarted, committed, or sent to the Dell. No real mic, mouse, keyboard or Lan Mouse
was used: fakes and recorded files only.

## Voice

| Change | Why |
|---|---|
| `daemon.py`: helpers `check_voice`, `is_near`, `should_learn`, `reopen_after` | Make the speaker check, near-miss rule, learning rule and mic-loss handling testable. Behaviour unchanged |
| `listen.fuzzy_wake`: fallback when `WAKE_LEAD` can't be imported | Don't crash a stub or partial install |
| New tests: speaker check off, parakeet variants, mic loss, wake | `speaker_check: false` path was untested |
| `voice_eval.py`: offline scorecard | Measure wake recall and speaker EER without the mic |
| Speaker threshold stays 0.36; negatives raise it only up to `CEILING`; learned entries that don't match the enrollment are ignored | The live profile had 18 of 33 poisoned entries. Defused without rewriting `voiceprint.json` |
| Wake variants jovers, jarbus, jovis; fuzzy match confirmed by Whisper | Recall 83.1% to 93.6% at 1.1% false wakes |

Open: `listen_loop` is not driven end to end by a test; push-to-talk with the check off
does not need "Jarvis" (decision for David).

## Remote control

15 findings reviewed, 13 fixed.

- **H1** a replaced session no longer deletes the new one's marker or restarts Lan Mouse
  mid-session; the restart is handed on and happens once, after the last session.
- **H2, H3** second mouse button and failed-request key tracking now always send releases.
- **M1** hub always keeps the newest frame. **M3** hidden tab ends at 15 s. **M4**
  Keyboard Lock in fullscreen and a leave-site prompt.
- **L1-L7** clear 404 message, no console shortcuts while live, edge clamping, back/forward
  blocked, wheel clamp, clearer timeout text, per-session monitor choice on Hyprland
  including rotated monitors.
- **L8** partly: failure text names what failed. SendInput result checks are not done.
- **M2** fixed by the input-sharing team: `ControllerPause.apply()` loops until the newest
  wish is applied, and its restore no longer reads as a start by hand.
- Not fixed: forwarding back/forward buttons, horizontal scroll.

Verified with 48 new lifecycle tests, 17 browser scenarios (14 failed on the old
`remote.js`) and headless Chrome at 1440, 1180, 720x450 and 320 wide.

## Core: gates

The first overhaul PERSIST widening blocked reading dotfiles (`awk 1 ~/.bashrc`,
`git status` in `~/.config/hypr`). Split into `PERSIST` (original) and `PERSIST_STARTUP`
(shell, X, fish, hypr, uwsm, environment.d, PowerShell profile), the latter checked only
against paths being written. Reads stay allowed; writes refuse with "JARVIS doesn't write
shell or desktop startup files". `systemctl status enable.service` is allowed again.

## Brain

- **F1** tools that ran before a usage-limit failure now travel on the exception, so the
  Claude stand-in does not re-run them.
- **F5** only the spoken lead (before the first blank line, table, list, heading, quote,
  code fence or URL) is voiced; a reply opening with a table says "The answer is on screen."
- **F6** a checker crash on a plain step keeps the worker's result, marked unchecked.

## Control and memory

`ctrl+u` no longer resets an unknown typed line to empty, which let `rm -rf` slip past the
gate after a click. Use `ctrl+c` in a terminal. Memory search now has direct tests for
`min_importance` and `ids`.
